# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security of users and data is a high priority for this project. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please report vulnerabilities by contacting the project maintainers directly or opening a private security advisory on GitHub.

### What to include in your report:
- A clear description of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Potential impact of the issue.

We will acknowledge receipt within 48 hours and work towards resolving the vulnerability promptly.
