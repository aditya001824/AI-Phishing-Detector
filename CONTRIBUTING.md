# Contributing to AI Phishing Detector

Thank you for your interest in contributing to **AI Phishing Detector**! 🎉

We welcome contributions of all kinds: bug fixes, feature requests, documentation improvements, new dataset samples, and machine learning enhancements.

---

## 🛠️ Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/<your-username>/AI-Phishing-Detector.git
   cd AI-Phishing-Detector
   ```
3. **Create a virtual environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Or `venv\Scripts\activate` on Windows
   ```
4. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

---

## 🧪 Running Tests

Before submitting a pull request, ensure all tests pass:

```bash
python -m unittest discover -s tests
```

---

## 📝 Submitting a Pull Request (PR)

1. Create a new feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
2. Make your changes with clear, concise commit messages (prefer conventional commit format `feat:`, `fix:`, `docs:`, `test:`).
3. Push to your fork:
   ```bash
   git push origin feature/my-new-feature
   ```
4. Open a Pull Request on GitHub describing your changes.

---

## 📜 Code of Conduct

Please be respectful and constructive in all issues and discussions.
